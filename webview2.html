How to interpret this report

Registered native bridges are positive evidence of embedding, but can be shimmed. Permissions API detection is not a reliable WebView discriminator in the collected samples; all three expose it. WKWebView, Safari, SFSafariViewController, and Chrome Custom Tabs cannot always be told apart by a webpage.

Some APIs are gated by HTTPS, permissions policy, system capabilities, feature flags, and browser version. API calls here never request camera, location, microphone, Bluetooth device pairing, or notification permission. This page contains no analytics, external scripts, or network requests.
